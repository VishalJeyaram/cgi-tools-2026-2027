# CGI Tools — MSc CAVE

This repository contains my weekly exercises, scripts, experiments, and notes for the **CGI Tools** class as part of the **MSc Computer Animation and Visual Effects (CAVE)** programme at **Bournemouth University**.

## About

The class focuses on using programming and scripting to build tools for CGI, animation, and VFX workflows.

This repository is used to keep track of my practical work throughout the module, including scripts written for DCC applications and general pipeline-related exercises.
